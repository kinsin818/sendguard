## 6. Long-path mechanism, and the host-manifest explanation that was refuted

`prefix_source` separates the two ways a `\\?\` path can appear: `recipe-explicit` (this harness
passed the prefix) versus `runtime-auto` (the argument was an ordinary plain path). 7 length cells
read `longpath_mechanism="prefix_rewrite"` with `prefix_source="runtime-auto"`: a plain path of
260-2201 characters succeeded while `LongPathsEnabled=0`.

The obvious explanation - the host manifest - was tested and does not hold
(`impl/csharp/apphost_probe.py`, report `D:\sg-cs-scratch\apphost-probe.json`):

| host | byte-scan hit_count of `longPathAware` | short point | 264-char plain point |
|---|---|---|---|
| `dotnet exec SendGuardProbe.dll` | 2 (in `dotnet.exe`) | ok | ok |
| published apphost `SendGuardProbe.exe` | **0** | ok | ok |

The apphost carries no such token and behaves identically, so the rewrite is done by the runtime. The
probe runs a green arm (a short path that must succeed) beside the long one, so "long-path-capable"
cannot be reported by a program that never ran. This is why `longpath_mechanism` and not `path_form`
decides the regime in section 5.

## 10. Scope choices carried forward, and their cost

- **Reserved-device cells are written with a zero-length payload** (`payload_policy="zero"`,
  `bytes_written=0`): 7 trap cells (`T01`, `T02`, `T10`, `T11`, `T14-m1..m3`) plus all 4 T-API rows =
  11 of 50. The contract forbids opening the *content* of those names, and a create-and-write on a
  name the OS maps to a device is a channel into that device (`PRN`, a serial port). Cost to the
  equality claim: `bytes_written=0` there is an instrument policy, not a language reading, and each
  affected cell says so in `type_II_note`.
- **Trap rows are measured on the pinned primary entry** `File.WriteAllBytes`; the rest of the pinned
  list is exercised where the frozen spec puts it, in `tapi`. So an entry disagreement on, say, T13 is
  invisible to this port's matrix - the cost is stated, not hidden.
- **`attribution_layer` is not emitted.** Deciding L1/L2/L3 needs the 2x2 across OS *and* language
  (`spec/attribution-tree.md` s1); one port on one OS cannot answer it without inventing the missing
  axis.
- **`build/obj` stay out of the repo.** The build command redirects both to `D:\sg-cs-scratch\`; the
  one-off `publish` used for section 6 does drop them next to the csproj, and those artifacts were
  removed after the round. `impl/csharp/` in the repo is five source files.
