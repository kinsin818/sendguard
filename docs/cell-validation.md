## What this does and does not say

- it says a cell carries the fields the frozen contract requires, with values inside the frozen enums. It does **not** say the cell is *true* - that is the sealed expectation table's question (`docs/expected-summary.md`) and the gate's (`docs/STATUS.md`);
- documented properties are checked; undocumented extra fields are **allowed** (additionalProperties=True) because a port that records how it measured something is doing the right thing, and a rule that punished that would be a rule against evidence;
- where this table and a port's own self-check disagree, this table is the one a stranger can reproduce, and the disagreement belongs in the acceptance sheet, not in a footnote.
