## The defect this run found, and what was asked about it

The folder line prints **seven** ports - `node` is counted - and name mode printed
`backed_by=T01,T02,T10,T11,T14 [68 cells, 7 ports]`. `ci/equality.py` reads six canonical faces and lists
`results/node` among the excluded ones (`spec/cell-identity.md` §9.5), because that port self-declared
`INSTRUMENT-RED`. So the deliverable was quoting a denominator the gate refuses to use, which is exactly the
kind of mismatch a customer would find first. The tool window was sent the two output lines, the rule to
load faces through, and the five commands to re-run; whatever it lands is recorded here rather than assumed.
