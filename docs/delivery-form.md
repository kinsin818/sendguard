## The three questions a buyer asks, and what can honestly be said

1. **What must be installed to run the checker?** The shipped deliverable is one Python file - `tool/check.py`, 81,759 bytes - and needs a Python 3 interpreter on `PATH` and nothing else: it imports the standard library only (`argparse, hashlib, json, os, re, sys, time, unicodedata`, plus `glob`, `uuid` and `subprocess` in local scopes - checked against the file, not remembered). Which interpreter this reading was taken on is a fact about a machine, so it is not printed here: `docs/host-stamp.md` carries it, and the reproducibility leg names that face as host-bound and does not compare it. A double-click on a machine with no interpreter is `NOT-MEASURED(no code signing, no installer built)`, which is the honest state, not a to-do slipped past the reader.

2. **How big is it?** The tracked answer is the table above: `14` artifact files carrying `310,141` bytes across the ports that commit any build output, and three ports that commit none. The checker itself is the file in item 1. No packaging step exists, and `0` installers of any format were found in the tree, so any size claim about a shipped product is unproven here and is not made.

3. **How long does it take?** The per-cell timings above are what the harnesses recorded around their own probes on one host, not wall-clock for a scan: they exclude compile time, they were taken while other lanes were running against the same disk, and the deliverable's own timing is `NOT-MEASURED(wall clock not recorded in any face)`. Publishing them anyway is better than a 'fast' adjective nobody has to defend.

## What this leg refuses to say

- It prints `NOT-MEASURED(<reason>)` rather than estimating. Three of the six rows above used to be sentences in a pitch; a number with no denominator is the failure mode this repository keeps catching in its own tools.
- It does not describe this working copy. Every artifact number above comes from the tracked file list, and the leg refuses to publish the table at all when that list cannot be trusted - a parse that returns one element filters out everything, and a filter that passes nothing is indistinguishable from an honest measurement of nothing. That is how this leg was wrong once, and the floor check is the record of it.
- It does not treat an absent `elapsed_ms` as a fast port. A missing measurement is a gap, and the count of cells that reported one is printed next to the number so nobody can quote the median without its `n`.
